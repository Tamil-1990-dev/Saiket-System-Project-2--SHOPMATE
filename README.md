# Project 2 — Mini E-Commerce (ShopMate)

This is a simple responsive e-commerce landing page built for an internship project.

Files:
- `index.html` — main page (Bootstrap layout)
- `style.css` — custom styles
- `script.js` — product rendering and interactivity

To run locally, open `index.html` in a browser. No build tools required.

Images are loaded from Unsplash (external URLs) for demo purposes.
