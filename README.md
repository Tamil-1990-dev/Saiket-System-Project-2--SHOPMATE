# 📌 Project Overview

**ShopMate** is a modern, responsive e-commerce website developed using **HTML5, CSS3, JavaScript, and Bootstrap 5**.

The project provides an attractive online shopping experience with multiple product categories, product search, shopping cart, wishlist, and responsive pages that work across desktop, tablet, and mobile devices.
